# 🏠 Clearing - カップル用バーチャル家計簿アプリ

**Clearing (クリアリング)** は、ふたりがそれぞれ支払った立替（支出）と共通口座への入金（収入）を記録し、毎月20日締め（21日〜翌20日）で相殺・清算するための「バーチャル共通口座」家計簿ダッシュボードです。

Google フォーム等で入力された Google スプレッドシートのデータをデータベースとして読み込み、Python の UI ライブラリ「Flet」によるモダンで視覚的なデスクトップ/Webダッシュボードを提供します。

---

## 🚀 主な機能
1. **カンタン起動 (PEP 723 対応)**: `uv run` を使うだけで、ライブラリの事前インストール不要で即時実行可能。
2. **自動セットアップアシスタント**: `credentials.json` やスプレッドシート設定が不足している場合、アプリ起動時に親切なガイダンスを表示します。
3. **柔軟な清算月判定**: タイムスタンプによる自動判定に加え、スプレッドシート側で個別に「対象清算月」を指定（上書き）可能。
4. **直感的な清算指示カード**: 「誰から誰へ、いくら送金すればよいか」を分かりやすく表示。
5. **月別サマリーと明細履歴**: 各自の合計貢献度をカードで可視化し、最新の取引履歴を一覧で表示。

## 🛠 使い方・セットアップ手順

### ステップ 1: API認証情報 (`credentials.json`) の取得
1. [Google Cloud Console](https://console.cloud.google.com/) にアクセスし、新しいプロジェクトを作成します。
2. **Google Sheets API** と **Google Drive API** を有効化します。
3. 「認証情報」メニューから**サービスアカウント**を作成します。
4. 作成したサービスアカウントの「キー」タブから **「鍵を追加」 > 「新しい鍵を作成」** を選択し、JSON形式でダウンロードします。
5. ダウンロードしたファイルを `credentials.json` というファイル名にリネームし、このプロジェクトフォルダ（`main.py` と同じ階層）に配置します。

### ステップ 2: スプレッドシートの作成と共有
1. 使用する Google スプレッドシートの「共有」ボタンをクリックします。
2. サービスアカウントのメールアドレス（例: `xxxx@yyyy.iam.gserviceaccount.com`）を入力し、**閲覧者** または **編集者** 権限を付与して共有します。
   *(※ アプリのセットアップ画面で、このアドレスを簡単にコピーできます。)*

### ステップ 3: アプリの起動と設定
1. ターミナルで本フォルダに移動し、以下のコマンドを実行します：
   ```bash
   uv run main.py
   ```
2. アプリのセットアップ画面が表示されたら、対象スプレッドシートのURL（またはキー）とシート名（任意）を入力します。
3. **「設定を保存して起動」** をクリックすると、設定が `config.json` に保存され、ダッシュボードが起動します！

## 📊 スプレッドシートのデータ構造 (列構成)
スプレッドシートの最初の5列は以下の構成にしてください（列ヘッダーの名称は自由ですが、順序は固定です）。

1. **A列: タイムスタンプ** (`YYYY/MM/DD HH:MM:SS` 形式。日時としてパースされます)
2. **B列: 金額** (数値。カンマや「円」などの記号が含まれていても自動で数値変換されます)
3. **C列: 支払った人** (`Aさん` または `Bさん`)
4. **D列: カテゴリ/メモ** (`共通口座への入金（収入）` または `食費` や `日用品` などの支出カテゴリ)
5. **E列: 対象清算月** (形式: `YYYY/MM`。特定の清算月に強制的に割り当てたい場合に入力。通常は空欄)

---

## 🧮 計算と清算ルール (仕様)

### 1. 対象清算月 (`billing_month`) の自動判定
毎月20日締めとして処理されます。
* **対象清算月 (E列) に記載がある場合:** その値を最優先します (例: `2026/07`)。
* **E列が空欄の場合:** タイムスタンプ (A列) の日付から自動判定します。
  * **20日以前の場合:** 当月の年月 (`YYYY/MM`)
  * **21日以降の場合:** 翌月の年月 (`YYYY/MM`)
  * *例: 2026/05/21 〜 2026/06/20 の日付のデータはすべて `2026/06` 清算月になります。*

### 2. データ分類
* **入金（収入）**: カテゴリが `共通口座への入金（収入）` である行。
  * $A_{inc}$ = Aさんの入金合計額
  * $B_{inc}$ = Bさんの入金合計額
* **共通支出**: カテゴリが `共通口座への入金（収入）` 以外のすべての行。
  * $A_{exp}$ = Aさんの立替合計額
  * $B_{exp}$ = Bさんの立替合計額

### 3. 清算額と送金アクションの算出
* **総貢献額の算出**:
  * Aさんの総貢献額： $Total_A = A_{inc} + A_{exp}$
  * Bさんの総貢献額： $Total_B = B_{inc} + B_{exp}$
* **差額の相殺**: $Diff = Total_A - Total_B$
  * **$Diff > 0$** の場合: **Bさん** から **Aさん** へ $\frac{Diff}{2}$ 円を送金
  * **$Diff < 0$** の場合: **Aさん** から **Bさん** へ $\frac{|Diff|}{2}$ 円を送金
  * **$Diff = 0$** の場合: 清算の必要はありません。
